> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Extend the current DAC S1/S2 runtime to mode1 differential-pair simulation, obtain at least 20% Qwen9B end-to-end speedup over local v2.1 at read_var=0.05, beat the matched v3 mode0 latency, and publish a verified GitHub v2.2 release containing optimized mode0 and mode1.

**Tech Stack:** Python 3.10+, PyTorch CUDA, Triton, pytest, Hugging Face Transformers, Nsight Systems, Git, PowerShell, SSH.

- [ ] **Step 3: Implement the estimator**

Use this public signature:

```python
def estimate_mode1_workspace(
    *,
    tokens,
    in_features,
    out_features,
    array_rows,
    array_cols,
    read_variation=0.0,
    weight_bytes=2,
    index_bytes=1,
    scale_bytes=4,
    vin_bytes=2,
    gdiff_bytes=2,
    output_bytes=4,
    execution_window_cols=0,
    streaming_prefetch_window=0,
):
    padded_in = _align_up(in_features, array_rows)
    padded_out = _align_up(out_features, array_cols)
    window_cols = _align_up(
        execution_window_cols or out_features,
        array_cols,
    )
    window_cols = min(padded_out, window_cols)
    weight_elements = padded_in * padded_out
    index_state = 2 * weight_elements * index_bytes
    scale_grid = (
        math.ceil(padded_in / array_rows)
        * math.ceil(padded_out / array_cols)
        * scale_bytes
    )
    signed_vin = tokens * padded_in * vin_bytes
    current_gdiff = padded_in * window_cols * gdiff_bytes
    prefetched_gdiff = current_gdiff * max(0, streaming_prefetch_window)
    output = tokens * padded_out * output_bytes
    preparation_peak = max(
        weight_elements * weight_bytes + index_state + scale_grid,
        index_state + scale_grid,
    )
    execution_peak = (
        index_state
        + scale_grid
        + signed_vin
        + current_gdiff
        + prefetched_gdiff
        + output
    )
    return WorkspaceEstimate(
        preparation_peak_bytes=preparation_peak,
        execution_peak_bytes=execution_peak,
        peak_bytes=max(preparation_peak, execution_peak),
    )
```

Count two compact index branches, one scale grid, one signed-DAC buffer, one current `Gdiff` window, optional next-window prefetch, and FP32 output. Do not multiply mode1 state by mode0 slice counts.
